# Public Boundary Notice

This public repository is limited to public-reference aggregate reproducibility materials for the Neotro Protocol quantum-computing execution-record observer-state mapping experiment.

## Included public layer

- Public full report PDF.
- Aggregate public data package ZIP.
- Track-level aggregate Q-state summaries.
- Source inventories.
- Public feature-group descriptions.
- Manifest and checksum records.
- Citation and release metadata.

## Excluded restricted layer

The repository does not include or authorize:

- Row-level Q-state assignment specifications.
- Exact assignment thresholds.
- Private calibration logic.
- Weighting logic or deployment-specific parameterization.
- Reconstruction-sensitive observer features.
- Operational deployment packages.
- Partner-side review logs.
- QPU workflow control.
- Decoder or QEC improvement method claims.
- Provider comparison or benchmark-superiority claims.
- Neotro certification, registry status, or operational license rights.

## Interpretation boundary

Q-state outputs are review-reference coordinates for public quantum execution records. They are not success/failure labels, anomaly verdicts, hardware rankings, decoder-performance verdicts, QEC-failure proofs, quantum-advantage claims, or operational commands.

If there is any conflict between casual interpretation and the public release boundary, `LICENSE.md` governs the public-reference license boundary.
